# Quick Start Guide - Word-like Super PDF Editor

## 🚀 Getting Started

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Launch the Application
```bash
python main.py
```

## 📖 5-Minute Tutorial

### 1. Opening a PDF (30 seconds)
- Click **"📄 Mở PDF"** button or press `Ctrl+O`
- Select your PDF file
- The PDF will display in the canvas area

### 2. Adding Text (1 minute)
- Click **"🔠 Chèn Chữ"** button
- Type your text in the dialog
- Choose font, size, and color
- Set the position (X, Y)
- Click **"Áp dụng"**

### 3. Formatting Text (1 minute)
- Use the **Formatting Toolbar** (second row)
  - **Font dropdown**: Select different fonts
  - **Size dropdown**: Choose text size
  - **B, I, U buttons**: Toggle bold, italic, underline
  - **Alignment buttons**: Align text left, center, right
  - **🎨 Màu button**: Pick text color

### 4. Adding Drawings (1 minute)
- Click **"─ Đường"** (line), **"□ Chữ nhật"** (rectangle), or **"○ Ellipse"**
- Click and drag on the canvas to draw
- Release to finish

### 5. Saving Your Work (30 seconds)
- Click **"💾 Lưu PDF"** or press `Ctrl+S`
- Choose save location
- Your edited PDF is ready!

## 💡 Common Tasks

### Selecting Elements
- **Click** on any text, image, or shape to select it (turns blue)
- Selected elements can be edited or deleted

### Deleting Elements
- **Right-click** on element → **"Xóa"**
- Or select element and press **Delete** key

### Undoing Mistakes
- Press **Ctrl+Z** for undo
- Press **Ctrl+Y** for redo
- Up to 50 undo levels available

### Adjusting Zoom
- Use the **Zoom slider** on the right panel
- Or use keyboard shortcuts
- Range: 50% to 200%

### Viewing Statistics
- Check the **Property Panel** on the right
- See element counts and types

## ⌨️ Essential Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Ctrl+O | Open PDF |
| Ctrl+S | Save PDF |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+B | Bold |
| Ctrl+I | Italic |
| Ctrl+U | Underline |
| Delete | Delete selected element |

## 🎯 Pro Tips

1. **Precision Positioning**: Use inch measurements for exact placement
2. **Color Consistency**: Use the same color picker for uniform design
3. **Batch Undo**: Multiple Ctrl+Z presses undo multiple actions
4. **Quick Font Change**: Use font dropdown without selecting text first
5. **Element Organization**: Delete and redraw for precise positioning

## 🔍 Troubleshooting

### Can't add text?
- Make sure a PDF is opened first
- Check that you clicked "Áp dụng" to confirm

### Changes not saving?
- Use Ctrl+S or File → Lưu PDF
- Make sure file location has write permissions

### Drawing not working?
- Click the drawing tool button first
- Then click and drag on the canvas
- Release to finish the shape

### Zoom too small?
- Use the zoom slider on the right panel
- Or use View menu options
